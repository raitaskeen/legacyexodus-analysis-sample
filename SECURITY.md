# Security Policy

## Supported Versions

Only the current main branch of this sample receives security considerations.

| Version | Supported |
| :--- | :--- |
| `0.1.x` | Yes |

---

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive information exposure within this sample:

1. **Do NOT open a public GitHub issue.**
2. Use GitHub's **Private Vulnerability Reporting** on the repository if enabled.
3. If private vulnerability reporting is unavailable, submit a confidential report to the repository owner via direct message on GitHub.

### What to Include in a Report
- Clear description of the vulnerability or leakage.
- Minimal reproduction steps or code snippet.
- Assessment of impact and potential exploit vectors.
- Any proposed remediation diff.
